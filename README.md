# Shopify Sales Analysis

## Project Overview
This project analyzes Shopify sales data using Python and Power BI to identify sales trends, product performance, and business insights.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- Microsoft Excel

## Dataset
The project uses the `Shopify Sales.xlsx` dataset for sales analysis.

## Project Objectives
- Analyze sales performance.
- Identify trends and patterns.
- Understand product performance.
- Create visual reports and business insights.

## Project Status
Dataset uploaded. Python analysis and Power BI dashboard development are the next steps.
