
# Shopify Sales Analysis

## Project Overview
This project analyzes Shopify sales data using Python and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI
- Git and GitHub

## Project Features
- Data cleaning
- Sales summary analysis
- Revenue by product visualization
- Monthly sales trend visualization
- Sales summary report

## Project Structure
- `python/` - Python analysis scripts
- `reports/` - Generated charts and summary report
- `powerbi/` - Power BI project files
- `data/` - Private local datasets (not uploaded)

## How to Run
Activate your Python environment and run:

```bash
python python/check_data.py
python python/clean_data.py
python python/analyze_sales.py
python python/visualize_sales.py
python python/generate_report.py
```

## Data Privacy
The original Excel dataset and CSV files are excluded from public GitHub uploads.
