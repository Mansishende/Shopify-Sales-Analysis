
# Shopify Sales Analysis

## Project Overview
This project analyses Shopify sales data using Python.
It calculates sales KPIs, explores product revenue,
visualises monthly sales trends, and generates a summary report.

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel / CSV
- Visual Studio Code

## Project Features
- Data cleaning and duplicate checking
- Total revenue calculation
- Unique order and customer counts
- Average order value calculation
- Product revenue chart
- Monthly sales trend chart
- Automated sales summary report

## Project Structure
- data/ - Local sales data (not published)
- python/ - Python analysis scripts
- reports/ - Generated charts and reports
- powerbi/ - Power BI project files
- screenshots/ - Dashboard screenshots

## How to Run
Install the dependencies:

    python -m pip install pandas openpyxl matplotlib

Run the scripts from the project root:

    python python/check_data.py
    python python/clean_data.py
    python python/analyze_sales.py
    python python/visualize_sales.py
    python python/generate_report.py

## Data Privacy
The original dataset is excluded because it may contain customer information.
